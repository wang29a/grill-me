# grill-me

一个让你被拷问到说不出话的 Agent Skill。

它不帮你改方案、不写代码、不给你安慰。它每轮只问你**一个**问题——当下最能戳穿你的那个，然后闭嘴等回答，一直问到方案站得住、或者最脆弱的那一环当众断裂。

> 别人都会帮你。只有它不会。

## 它解决什么问题

大多数 AI 对话默认站在你这边：你说一个想法，它帮你补全、润色、找理由。结果是你在一个没有阻力的环境里，把没验证过的假设越堆越高。

`grill-me` 反过来用。它不是审阅（review）：当你已经有一个成形的主张时，它不给建议、不给替代方案——因为一旦它给出方案，你就从"思考"切换成了"评价它的方案"，而你的漏洞一个都没动。

**但锋利不等于准确。** 一份靠表演严重性得出的复盘，比一份诚实标注不确定性的复盘更没用。所以它现在强制区分"我有多大把握"和"如果为真有多糟"。

## 三种模式

入口先做一次分流：**你手上是已经成形的主张，还是想先看东西再决定要什么？** 前者进入访谈；后者先问两三个必要的上下文问题（使用场景、已有约束、过去的具体经历），再给一小块样例让你对着它反应，然后继续追问——**还没形成偏好，不等于没有可问的信息**。你不回答这个分流问题时，它不会再问第二遍，直接按最可能的读法走。模式不用你选：

| 模式 | 触发场景 | 攻击目标 |
|---|---|---|
| **设计** | 你抛出一个方案、产品、架构、论文、skill | 它该不该存在、边界对不对、能不能度量 |
| **学习** | 你声称理解了某个概念，或要求检验 | 你掌握的是机制，还是背下来的术语 |
| **决策** | 你正在几个选项之间选，或即将下注 | 这个选择是真的吗、代价标价了吗、动机诚实吗 |

## 核心机制

**每轮只问一个问题。** 批量提问会让你挑软柿子捏，把最难的那个埋掉。

**不许安慰。** 不说"好问题"，不说"当然这只是我的看法"。夸奖会消耗掉它唯一的优势。

**不许给建议。** 你问它意见，它只会说："还没有轮到我说。先回答刚才那个问题。"

**不接受模糊答案。** "应该没问题""差不多""视情况而定""我们会迭代"——都不算回答。要么给出数字、日期、名字，要么承认不知道。而"不知道"被记为一条发现，不是失败。

**一轮只要一个答案。** 判断标准不是语法，是**它需要几个回答**。"你现在是有一个成形的方案要我挑刺，还是想先看看东西？" 含"还是"，但只要求做一次选择，是合规的一个问题。看不懂时会**换个更短的说法重问**，而不是判你回避——"没看明白"不等于"在躲"。

**先分类再开口。** 动手前它必须把自己的东西分成三桶：你说的原话、它的合理推断、它自己的假设。三桶**都可以追问**；分类只决定**怎么标注问题**，不决定能不能问。尤其是你亲口说出的主张——"我的系统支持十万并发"——正是最该被追问的目标，不是豁免对象。

**七步弧是菜单，不是流程。** 强制具体 / 挖隐含假设 / 证伪条件 / 利益与激励 / 成本与可逆性 / 最弱点针刺 / 收尾一问——**开头最多挑两步**贴合当前主张的；两步是初始聚焦，不是上限，出现新证据就换步骤。

**结束产物：先记事实，再分级。** 三类陈述分开处理：**观察到的事实**（"这次三问未回答"）直接记录，不需要证据支撑；**解释**（"用户在回避"）需要证据，没有就降级；**预测**（"这个方案会失败"）需要推理，也是唯一带严重度等级的一类。风险清单另有独立两列——"如果为真有多糟"和"我有多大把握它是真的"；一个没有证据的严重风险会被标成 `高严重度 / 低置信度`，而不是含糊地写成"致命"。清单里还有一栏：**什么能推翻上面的判断**——缺这一栏时，只降级解释性判断，不降级已记录的事实。

**它也会停手**：最弱点被追问并得到**具体**回答（"应该没问题"不算回答，那是要继续追问的信号）、你说停、**连续三轮没有新信息**、满 12 问、或发现你其实还没有成形的主张。判断进展看"讨论是否还在产生信息"，不看"你是否改变立场"——一个扛住了六轮精确追问的主张是值得报告的结果，不是没问够。为了显得凶而继续硬问，正是它在猎捕的那种失败模式。

## 它不做什么

`grill-me` 攻击**已经存在的主张**。如果你还在探索"我到底想要什么"，它不会假装能靠访谈把答案问出来——它会先问必要的上下文，再给你一块最小的样例，让你对着具体东西产生反应。

这个边界是代价换来的。skill 被打回过两次：第一版把严重度当结论、把没回答当回避、把推测写成事实；第二版虽然加了证据纪律，却又写出了几条自相矛盾的规则（用语法判断问题数量、只允许追问推断、用户一回应就停手）。现在的版本以**规则彼此一致**为准，而不是继续堆规则。

## 安装

Skill 就是一个 `SKILL.md` 文件，任何支持 skill 的 agent harness（Claude Code、DSH 等）都能用。

**通用**：把 `grill-me/` 整个目录放进你 harness 的 skills 目录。

**DSH**：仓库里已经带好了 `.dsh/skills/grill-me` 符号链接入口，克隆到你当前的工作目录即可被自动发现：

```sh
git clone https://github.com/wang29a/grill-me.git
# 在项目根目录下，agent 会自动发现 .dsh/skills/grill-me
```

其他位置：
- `<项目根>/.dsh/skills/grill-me/SKILL.md` — 只对当前项目生效
- `~/.dsh/skills/grill-me/SKILL.md` — 对你所有项目生效

**Claude Code**：把 `grill-me/` 放进 `~/.claude/skills/` 或项目的 `.claude/skills/`（目录名 `grill-me`，内含 `SKILL.md`）。

## 使用

直接说：

```
拷问我：我想做一个 XXX
grill me on this design
挑战我，我觉得我已经理解了 Raft 的选主过程
我该不该辞职去做这个
```

也可以作为命令调用（支持 skill 命令的 harness）：`/grill-me`

## 仓库结构

```
grill-me/SKILL.md            # 唯一的实质内容
.dsh/skills/grill-me -> ../../grill-me   # DSH 自动发现入口
README.md
LICENSE
```
